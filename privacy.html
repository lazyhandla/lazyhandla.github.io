개인정보처리방침

적용 대상: LazyHand 구인광고 자동 올리기 (Windows 앱) · 최종 수정일 2026년 10월 2일

1. 수집하는 정보

앱에 입력하신 라디오코리아 아이디·비밀번호, 광고 제목·내용, 지역, 직종, 연락처, 담당자, 직원 수, 급여 범위, 올리는 기간과 시간, 그리고 선택해서 적으신 회사명과 이메일입니다. 앱은 설치할 때 무작위 설치 번호(UUID) 하나를 만듭니다. 이 번호는 이름·계정·기기 정보와 연결되지 않습니다.

2. 저장 위치

입력하신 정보는 사용자의 컴퓨터 안에 저장됩니다. 비밀번호는 Windows 암호화(DPAPI)로 저장되어 해당 컴퓨터의 해당 사용자만 풀 수 있습니다. 아이디·비밀번호와 광고 본문(내용)은 LazyHand로 절대 보내지 않습니다. LazyHand로 가는 정보는 아래 4~8번에 적힌 것뿐입니다.

3. 사용 목적과 전송

입력하신 정보는 라디오코리아(radiokorea.com)에 로그인하고 구인광고를 올리는 데 쓰입니다. 광고 도구나 쿠키 추적은 쓰지 않습니다. LazyHand로 보내는 것은 4번(익명 사용 통계), 5번(광고 정보 공유, 켠 경우만), 6번(소식 이메일, 신청한 경우만), 7번(웹사이트 방문 집계), 8번(오류 알림, 켠 경우만)뿐입니다. 4~7번은 암호화된 연결(HTTPS)로 LazyHand가 소유한 Google 설문지(Google Forms)와 Google 스프레드시트에 저장되고, 판매하거나 다른 곳에 넘기지 않습니다.

4. 익명 사용 통계 (기본 켜짐 · 끌 수 있음)

프로그램이 몇 대에 설치되어 쓰이는지 알기 위해, 앱이 켜져 있는 날 하루 한 번 다음만 보냅니다: 무작위 설치 번호(UUID), 앱 이름, 앱 버전, Windows 버전. 이름, 계정, 광고 내용, 연락처는 보내지 않고 IP 주소도 따로 저장하지 않습니다. 앱의 “익명 사용 통계(설치 수)를 보내요”를 끄면 더 이상 보내지 않습니다. 인터넷이 끊겨 못 보낸 것은 컴퓨터에 최대 50개까지 잠시 보관했다가 나중에 보냅니다.

5. 올라간 광고 정보 공유 (기본 켜짐 · 끌 수 있음)

앱의 “올라간 광고 정보를 LazyHand와 공유해요”는 처음에 켜져 있으며(버전 1.0.2부터), 앱 화면에서 언제든 체크를 풀어 끌 수 있습니다. 켜져 있으면 광고가 실제로 올라갈 때마다 다음만 보냅니다: 설치 번호, 앱 버전, 회사명(적지 않으면 담당자), 광고 제목, 지역, 직종, 연락처, 올린 시각, 올라간 글의 라디오코리아 링크. 모두 라디오코리아에 이미 공개되는 내용이며, 아이디·비밀번호·광고 본문은 보내지 않습니다. 목적은 프로그램이 실제로 어떻게 쓰이는지 알고 무료 프로그램을 계속 개선하는 것과, LazyHand 서비스 안내입니다. 언제든 체크를 풀면 바로 멈추고, 아직 못 보낸 것도 지웁니다. “회사명”은 이 공유에만 쓰이고 라디오코리아에는 올라가지 않습니다.

6. 소식 이메일 (선택 · 기본 꺼짐)

이메일을 적고 “LazyHand 소식 이메일 받기”를 직접 체크한 경우에만, 저장할 때 이메일 주소·설치 번호·앱 버전을 한 번 보냅니다(이메일을 바꾸면 다시). 프로그램 업데이트와 LazyHand 소식을 보내는 데에만 씁니다. 그만 받으려면 언제든 lazyhandla@gmail.com 으로 메일 주시면 목록에서 지웁니다.

7. 웹사이트 방문 집계

LazyHand 웹사이트는 앱 안의 링크로 들어온 경우에만(주소에 ?from=가 붙은 경우) 방문 한 번을 셉니다. 보내는 것은 어느 링크로 왔는지(from), 본 페이지 주소, 이전 사이트의 도메인(전체 주소가 아닌 origin만), 브라우저 언어뿐입니다. 쿠키를 쓰지 않고, 그 밖의 추적은 하지 않습니다. 일반 방문은 세지 않습니다.

8. 오류 자동 알림 (선택 · 기본 꺼짐)

앱의 “오류가 나면 LazyHand에 자동으로 알리기”는 처음에 꺼져 있으며, 사용자가 직접 켠 경우에만 동작하고 언제든 끌 수 있습니다. 켜 두면 로그인 실패, 라디오코리아 화면 변경, 예기치 않은 오류가 생겼을 때 다음 내용만 보냅니다: 앱 이름과 버전, Windows 버전, 오류 시각, 오류 요약, 앱 기록(로그)의 마지막 40줄. 보내기 전에 앱이 비밀번호, 아이디, 광고 제목·내용, 연락처, 담당자, 급여, 이메일 주소, 전화번호, 인증 토큰, Windows 사용자 이름을 지웁니다. 전송은 암호화된 연결(HTTPS)로 FormSubmit(formsubmit.co) 양식 전달 서비스를 거쳐 LazyHand 메일(lazyhandla@gmail.com)로만 가며, 오류를 고치는 데에만 쓰고 판매하거나 공유하지 않습니다. 같은 오류는 하루 1번, 전체 하루 5번까지만 보냅니다.

9. 원격 지원 (빠른 지원)

“원격 지원 요청” 버튼은 Windows에 들어 있는 Microsoft의 빠른 지원(Quick Assist) 앱을 열기만 합니다. 원격 연결은 사용자가 직접 보안 코드를 입력하고 화면 공유를 허용해야만 시작되며, 창을 닫으면 언제든 끝납니다. 연결 중의 화면 공유는 Microsoft의 빠른 지원과 Microsoft 개인정보처리방침을 따르고, LazyHand 앱은 그 내용을 저장하거나 전송하지 않습니다. “문의 메일 보내기”는 사용자의 메일 프로그램에 앱 이름·버전·Windows 버전·기록 파일 위치를 미리 적어 열 뿐이며, 보낼지는 사용자가 정합니다.

10. 보관과 삭제

앱을 제거하면 컴퓨터에 저장된 정보도 함께 삭제됩니다. 앱 안에서 언제든 내용을 수정하거나 지울 수 있습니다. LazyHand로 보내진 정보(4~8번)를 지우고 싶으면 lazyhandla@gmail.com 으로 알려주세요. 확인 후 지웁니다.

11. 제3자

LazyHand는 라디오코리아와 관련 없는 독립 프로그램입니다. 라디오코리아에 올라간 글은 라디오코리아의 정책을 따릅니다. 4~7번 정보는 Google(Google Forms·스프레드시트)에, 오류 자동 알림을 켠 경우 FormSubmit에, 원격 지원을 사용한 경우 Microsoft 빠른 지원에 위에 적힌 범위에서 저장·전달됩니다.

Privacy Policy

Applies to: LazyHand Job Ad Auto Poster (Windows app) · Last updated October 2, 2026

Data

The app stores the RadioKorea login, ad text, schedule and the optional company name and email you enter on your own computer. The password is encrypted with Windows DPAPI. On install the app creates a random install ID (UUID) that is not linked to your name, account or device. Your RadioKorea ID, password and ad body text are never sent to LazyHand.

Use

Your information is used to sign in to radiokorea.com and post your job ad. No advertising tools and no cookie tracking. The only things sent to LazyHand are listed below: anonymous usage stats, opt-in ad-info sharing, opt-in email signup, website visit counting, and opt-in error reports. Except for error reports, these go over HTTPS to Google Forms / Google Sheets owned by LazyHand, and are never sold or shared.

Anonymous usage stats (on by default, can be turned off)

To count active installs, once per day while the app runs it sends only: the random install ID, app name, app version and Windows version. No name, account, ad content or contact details are sent, and no IP address is stored. Turn off “익명 사용 통계(설치 수)를 보내요” (anonymous usage stats) in the app to stop. If you are offline, up to 50 pending items are kept on your PC and sent later.

Sharing posted-ad info (on by default, can be turned off)

“올라간 광고 정보를 LazyHand와 공유해요” (share posted ad info) is on by default (from version 1.0.2) and can be unticked in the app at any time. When on, after each ad that is actually posted it sends only: install ID, app version, company name (or the manager name if blank), ad title, region, job category, contact, time posted, and the RadioKorea link of the new post — all information already public on RadioKorea. Never your ID, password or ad body. Purpose: understanding how the free app is used so we can keep improving it, and telling you about LazyHand services. Untick it at any time to stop; pending items are deleted. The company name field is used only for this and is not posted to RadioKorea.

Email signup (optional, off by default)

Only if you enter an email and tick “LazyHand 소식 이메일 받기” (receive LazyHand news), the app sends your email address, install ID and app version once when you save (again only if you change the email). Used only to send app updates and LazyHand news. To unsubscribe, email lazyhandla@gmail.com at any time.

Website visit counting

The LazyHand website counts a visit only when you arrive from a link inside the app (the address has ?from=). It sends only: which link you came from, the page path, the referring site’s origin (not the full address) and your browser language. No cookies and no other tracking; ordinary visits are not counted.

Optional error reports (off by default)

The setting “Automatically tell LazyHand when an error occurs” is off by default; it works only if you turn it on, and you can turn it off at any time. When on, and a login failure, a RadioKorea page change or an unexpected error occurs, the app sends only: app name and version, Windows version, time of the error, a short error summary, and the last 40 lines of the app log. Before sending, the app removes passwords, your user ID, ad title and text, contact, manager, salary, email addresses, phone numbers, access tokens and your Windows user name. Reports travel over HTTPS through the FormSubmit form-forwarding service (formsubmit.co) to LazyHand’s mailbox (lazyhandla@gmail.com) only, are used only to fix problems, and are never sold or shared. At most one report per distinct error per day and five per day in total.

Remote support (Quick Assist)

The “Request remote support” button only opens Microsoft Quick Assist, a tool built into Windows. A remote session starts only after you enter a security code and allow screen sharing yourself, and you can end it at any time by closing the window. The session is governed by Microsoft Quick Assist and Microsoft’s privacy statement; the LazyHand app does not record or transmit it. “Send support email” just opens your own email program prefilled with the app name, version, Windows version and log file location; you decide whether to send it.

Retention and deletion

Uninstalling the app deletes all data stored on your computer. You can edit or clear it in the app at any time. To have data that was sent to LazyHand deleted, email lazyhandla@gmail.com and we will remove it.

Third parties

LazyHand is independent and not affiliated with RadioKorea. Usage stats, shared ad info, email signups and visit counts are stored with Google (Google Forms / Sheets); error reports, if enabled, pass through FormSubmit; remote support uses Microsoft Quick Assist — each only to the extent described above.
