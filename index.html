A사에서 실제로 쓰고 있는 프로그램을 다른 분들도 무료로 쓰실 수 있게 Microsoft Store에 제출했고, 지금 심사 중이에요. Windows 10·11용 · 라디오코리아와 관련 없는 독립 프로그램이에요.

쓰시던 프로그램에 연결.

쓰시던 프로그램은 그대로 두고, 반복 작업만 줄여드려요.

    로고는 연결해 본 적 있거나 연결 가능한 프로그램이에요. 연동 가능 여부와 방식은 사용 환경을 확인한 뒤 알려드려요.

    제작 과정.

    처음부터 끝까지 온라인으로 진행해요.

    1. 무료 상담문의 폼에 반복하는 일을 적어주세요. 자동화가 가능한지, 어떤 방식이 맞는지 무료로 알려드려요.
    2. 견적작업 범위와 비용, 일정을 이메일로 알려드려요. 진행이 정해지면 선금 50%로 시작해요.
    3. 제작 · 테스트실제 데이터로 돌려보면서 회사 업무에 맞는지 함께 확인해요.
    4. 인도 · 지원사용법을 알려드리고, 인도 후 60~90일 동안 만든 기능의 오류는 무상으로 고쳐드려요.

    비용 · 지원.

    제작비는 어떻게 정하나요?

    작업 범위를 보고 견적을 드려요. 결제는 선금 50%, 완료 후 50%예요.

    매달 내는 비용이 있나요?

    LazyHand 월 사용료는 없어요. 연결하는 외부 서비스에 자체 요금이 있다면, 그 요금만 해당 서비스에 직접 내시면 돼요.

    얼마나 걸리나요?

    작업 범위에 따라 달라요. 견적을 드릴 때 일정도 함께 알려드려요.

    만든 뒤 수정·지원은요?

    인도 후 60~90일 동안(프로젝트 규모에 따라 견적서에 확정) 아래와 같이 지원해 드려요.

    • 만든 기능의 오류 수정 · 무상
    • 새 기능 추가 · 별도 견적
    • 연결된 외부 프로그램·사이트가 바뀌어 생기는 수정 · 별도 견적

    기간 이후의 지원은 별도로 협의해요.

    설치·업데이트·수리는 어떻게 하나요?

    전부 원격으로 해요. 설치는 보내드리는 링크를 한 번 누르면 끝나고, 업데이트는 프로그램이 알아서 받아요. 문제가 생기면 프로그램 안의 ‘원격 지원 요청’ 버튼을 누르고 화면에 나오는 코드를 이메일로 보내주시면, Windows 기본 기능인 빠른 지원으로 접속해서 고쳐드려요. 방문이나 전화는 필요 없어요.

    업무 시간에 문제가 생기면요?

    납품 후 오류 신고는 이메일로 24시간 접수해요. 프로그램이 멈춰 업무가 막히는 장애는 접수 당일 저녁에 우선 처리하고, 일반 수정 요청은 평일 저녁·주말에 처리해요.

    상담은 어떻게 하나요?

    상담·견적 문의는 문의 폼이나 이메일로만 받고, 평일 저녁과 주말에 답변드려요. 전화 상담은 없어요.

    우리 프로그램도 연결되나요?

    사용 중인 프로그램과 환경을 확인한 뒤, 연결이 가능한지와 방식을 알려드려요.

    데이터·비밀번호는 안전한가요?

    프로그램은 회사 PC나 회사 계정 안에서 동작하고, 작업에 필요한 권한만 사용해요. 어떤 데이터에 접근하는지는 제작 전에 먼저 설명드려요.

    LazyHand 소개.

    LazyHand는 LA에서 의류 도매 회사를 운영하는 사람이 만들어요. 주문, 재고, 배송, 정산처럼 날마다 반복되는 일을 직접 하다가, 하나씩 프로그램으로 바꿔 왔어요.

    그렇게 만든 프로그램은 지금도 매일 저희 회사에서 돌아가고 있어요. 위 사례 속 A사가 바로 그 회사예요.

    직접 써 보고 효과를 본 방식 그대로, 다른 회사의 업무에 맞춰 만들어 드려요.

    반복 업무, 이제 맡기세요.
